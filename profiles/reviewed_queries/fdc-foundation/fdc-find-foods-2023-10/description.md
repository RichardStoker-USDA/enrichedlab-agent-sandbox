# Find Foundation Foods by description (October 2023), version 1

Generated by `scripts/generate_fdc_release_tools.py` from the reviewed `fdc-foundation-2026-04` tool `fdc-find-foods`
for `fdc-foundation-2023-10`, FoodData Central Foundation Foods (October 2023). The template uses unqualified relation
names, which the read transaction binds to the release's schema `fdc_foundation_2023_10`.

Differences from April 2026: the release has no `food_category` table, so the template returns `NULL::text AS
food_category` and drops that join.

The phrase is matched with `ILIKE '%' || phrase || '%'` against `food.description`, restricted to the release's
`foundation_food` rows, so sample, sub-sample and acquisition foods are left out. SQL wildcards `%` and `_` keep their
meaning. Ordering: an exact case-insensitive match first, then shorter descriptions, then the description in byte order
and the FDC id, so selection at the limit is stable. A row-number predicate applies the typed limit (1 to 100, default
25) while the outer SELECT keeps the guard's fixed LIMIT 100. Empty text lists every Foundation Food.

Checked as `fdc_foundation_2023_10_reader` in a read-only transaction (counts only): "milk" returned
15 matches, empty text returned 100 of the 265 Foundation Foods, each with an empty food_category, a phrase with no
match returned none, and the first food's own description put that food first.
