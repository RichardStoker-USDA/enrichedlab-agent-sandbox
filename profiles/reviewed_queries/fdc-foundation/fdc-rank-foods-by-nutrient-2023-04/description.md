# Rank Foundation Foods by one nutrient (April 2023), version 1

Generated by `scripts/generate_fdc_release_tools.py` from the reviewed `fdc-foundation-2026-04` tool
`fdc-rank-foods-by-nutrient` for `fdc-foundation-2023-04`, FoodData Central Foundation Foods (April 2023). The template
uses unqualified relation names, which the read transaction binds to the release's schema `fdc_foundation_2023_04`.

Differences from April 2026: the release has no `food_category` table, so the template returns `NULL::text AS
food_category` and drops that join.

Ranks Foundation Foods by `food_nutrient.amount` (per 100 g) for one nutrient id, highest or lowest first (closed
choice, default highest), with a typed limit of 1 to 100 (default 20) and the guard's fixed LIMIT 100 on the outer
SELECT. Rows without an amount are left out. Ties order by description in byte order, FDC id and row id, so selection at
the limit is stable. Where the release publishes two amounts for one food and nutrient, both rows are ranked, so such a
food can appear twice. Nutrient ids come from `fdc-food-nutrients-2023-04`.

Checked as `fdc_foundation_2023_04_reader` in a read-only transaction (counts only): protein (1003)
highest returned 20 rows for 20 distinct foods in descending order; vitamin C (1162) lowest returned 10 rows in
ascending order.
