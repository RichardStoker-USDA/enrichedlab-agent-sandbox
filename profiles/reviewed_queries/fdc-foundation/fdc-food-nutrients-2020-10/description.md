# Nutrient profile of one Foundation Food (October 2020), version 1

Generated by `scripts/generate_fdc_release_tools.py` from the reviewed `fdc-foundation-2026-04` tool
`fdc-food-nutrients` for `fdc-foundation-2020-10`, FoodData Central Foundation Foods (October 2020). The template uses
unqualified relation names, which the read transaction binds to the release's schema `fdc_foundation_2020_10`.

Differences from April 2026: none.

Lists `food_nutrient` rows joined to `nutrient` for one FDC id that is a Foundation Food in the release (an id of a
sample or sub-sample food returns no rows). Amounts are per 100 g as USDA publishes them; `data_points`, `min`, `max`
and `median` are passed through unchanged (null where unpublished). Ordering follows the release's `nutrient.rank`, then
the nutrient number and name in byte order and the row id. Where the release publishes two amounts for one food and
nutrient, both rows are listed; duplicates are not merged.

Checked as `fdc_foundation_2020_10_reader` in a read-only transaction (counts only): the first
Foundation Food returned 119 rows with 119 distinct nutrients, 119 with an amount; an id that is not a Foundation Food
returned none; the release publishes no food and nutrient pairs with two amounts.
