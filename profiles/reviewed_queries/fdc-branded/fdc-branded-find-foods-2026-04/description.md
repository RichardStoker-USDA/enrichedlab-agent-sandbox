# Find Branded Foods by description (April 2026), version 1

Generated by `scripts/generate_fdc_data_type_tools.py` for `fdc-branded-2026-04-r2`, FoodData Central Branded Foods
(April 2026). It follows the reviewed Foundation tool of the same purpose with `branded_food` in place of
`foundation_food`, so only Branded Foods are read; that table is unique on `fdc_id`, so no food repeats. Unqualified
relation names bind to the source's schema `fdc_branded_2026_04`.

The phrase is matched against the description, the brand name and the brand owner; the exact-match ordering looks at the
description only. Empty text lists every Branded Food, about two million rows sorted, so it is the slowest call.

Checked as `fdc_branded_2026_04_reader` in a read-only transaction (counts only): "milk" returned 25
matches (5.1 s), empty text returned 100 of the 1999950 Branded Foods (7.6 s), each with its brand owner, a phrase with
no match returned none, and the first food's own description put that food first.
