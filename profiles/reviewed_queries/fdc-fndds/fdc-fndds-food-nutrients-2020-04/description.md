# Nutrient profile of one FNDDS survey food (April 2020), version 1

Generated by `scripts/generate_fdc_data_type_tools.py` for `fdc-fndds-2020-04`, FoodData Central FNDDS survey foods
(April 2020). It follows the reviewed Foundation tool of the same purpose with `survey_fndds_food` in place of
`foundation_food`, so only FNDDS survey foods are read; that table is unique on `fdc_id`, so no food repeats.
Unqualified relation names bind to the source's schema `fdc_fndds_2020_04`.

FNDDS amounts are per 100 g of the food as consumed; FNDDS publishes no analytical data points, so `data_points`,
`min_amount`, `max_amount` and `median_amount` are empty where the release leaves them so.

The WWEIA category joins `wweia_food_category.wweia_food_category_code` to `survey_fndds_food.wweia_category_code`, the
column names this release uses; each WWEIA code is unique.

Checked as `fdc_fndds_2020_04_reader` in a read-only transaction (counts only): the first FNDDS
survey food returned 65 rows with 65 distinct nutrients, 65 with an amount and 0 with data points; an id that is not one
of the release's FNDDS survey foods returned none; the release publishes no food and nutrient pairs with two amounts.
