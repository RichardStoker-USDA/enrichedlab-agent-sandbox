# Rank FNDDS survey foods by one nutrient (April 2019), version 1

Generated by `scripts/generate_fdc_data_type_tools.py` for `fdc-fndds-2019-04`, FoodData Central FNDDS survey foods
(April 2019). It follows the reviewed Foundation tool of the same purpose with `survey_fndds_food` in place of
`foundation_food`, so only FNDDS survey foods are read; that table is unique on `fdc_id`, so no food repeats.
Unqualified relation names bind to the source's schema `fdc_fndds_2019_04`.

The WWEIA category joins `wweia_food_category.wweia_food_category_code` to `survey_fndds_food.wweia_category_code`, the
column names this release uses; each WWEIA code is unique.

Checked as `fdc_fndds_2019_04_reader` in a read-only transaction (counts only): protein (1003)
highest returned 20 rows for 20 distinct foods in descending order; vitamin C (1162) lowest returned 10 rows in
ascending order.
