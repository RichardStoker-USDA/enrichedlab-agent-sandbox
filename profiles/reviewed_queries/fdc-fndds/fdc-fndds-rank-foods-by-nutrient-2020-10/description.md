# Rank FNDDS survey foods by one nutrient (October 2020), version 1

Generated by `scripts/generate_fdc_data_type_tools.py` for `fdc-fndds-2020-10`, FoodData Central FNDDS survey foods
(October 2020). It follows the reviewed Foundation tool of the same purpose with `survey_fndds_food` in place of
`foundation_food`, so only FNDDS survey foods are read; that table is unique on `fdc_id`, so no food repeats.
Unqualified relation names bind to the source's schema `fdc_fndds_2020_10`.

The WWEIA category joins `wweia_food_category.wweia_food_category` to `survey_fndds_food.wweia_category_number`, the
column names this release uses; each WWEIA code is unique.

Checked as `fdc_fndds_2020_10_reader` in a read-only transaction (counts only): protein (1003)
highest returned 20 rows for 20 distinct foods in descending order; vitamin C (1162) lowest returned 10 rows in
ascending order.
