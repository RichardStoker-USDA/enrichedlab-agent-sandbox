# Find SR Legacy foods by description (April 2018), version 1

Generated by `scripts/generate_fdc_data_type_tools.py` for `fdc-sr-legacy-2018-04`, FoodData Central SR Legacy (April
2018). It follows the reviewed Foundation tool of the same purpose with `sr_legacy_food` in place of `foundation_food`,
so only SR Legacy foods are read; that table is unique on `fdc_id`, so no food repeats. Unqualified relation names bind
to the source's schema `fdc_sr_legacy_2018_04`.

Checked as `fdc_sr_legacy_2018_04_reader` in a read-only transaction (counts only): "milk" returned
25 matches, empty text returned 100 of the 7793 SR Legacy foods, each with its food category, a phrase with no match
returned none, and the first food's own description put that food first.
