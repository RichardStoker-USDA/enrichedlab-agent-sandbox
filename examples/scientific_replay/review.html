Method

Observations are grouped by supplement and dose. R calculates the count, mean, median and sample standard deviation for each group. No observations are removed or imputed. Input checks cover column names, missing values, finite measurements and positive dose.

Reproduce the analysis

Use the included data and script in your own R environment. The original results stay unchanged; new results go into a separate folder.

  1. Download and extract the analysis

    The ZIP contains the input data, R code, figures, results, logs and file checksums. Open a terminal in the extracted folder.

  2. Check the files

    With Python 3.11 or later installed, run:

    python3 scripts/package.py verify .

  3. Run and compare

    With R installed, this command runs the method and compares its numeric results with the original:

    python3 scripts/package.py rerun .

    To use RStudio, open the extracted folder as your working directory, then run this in its Terminal tab:

    Rscript scripts/analysis.R inputs/observations.csv rstudio_results

  4. Inspect the new results

    Open rerun/figure.pdf and rerun/summary.csv. The comparison uses an absolute and relative numeric tolerance of 1e-12. Graphics may differ across R installations; rerun/graphics.txt records SVG availability.
